# mvchess: Maldivian Chess

A two-player (hot-seat) chess game in one file, `index.html`. Double-click it to play in any browser.

The rules are standard chess. Only the pieces are themed: Sultan = King, Dhoni = Queen, Coral = Bishop, Fish = Knight, Beach Hut = Rook, Shell = Pawn.

Tests: `node tests/movegen.test.js` (move counts, castling, en passant, promotion, game-end detection).
